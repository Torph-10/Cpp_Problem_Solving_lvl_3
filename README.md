# C++ Problem Solving: Level 3

My solutions to the Level 3 problem-solving challenges in C++. Each problem is solved in its own file or folder, with the focus on clean logic, reusable functions and well-structured code.

Part of a three-level series:
- [Level 1](https://github.com/Torph-10/Cpp_Problem_Solving_lvl_1)
- [Level 2](https://github.com/Torph-10/Cpp_Problem_Solving_lvl_2)
- **Level 3** (this repository)

## What This Repository Covers

- Breaking a problem into smaller steps before writing code
- Using functions to keep solutions readable and reusable
- Working with arrays, strings, structures and vectors
- Applying loops, conditions and validation to handle different inputs
- Testing solutions against several inputs and edge cases

## Getting Started

### Requirements
- A C++ compiler such as `g++` (C++11 or newer)

### Clone the repository

```bash
git clone git@github.com:Torph-10/Cpp_Problem_Solving_lvl_3.git
cd Cpp_Problem_Solving_lvl_3
```

### Compile and run a solution

```bash
g++ -Wall -Wextra -std=c++17 solution.cpp -o solution
./solution
```

Replace `solution.cpp` with the file you want to run. If a file or folder name contains spaces, wrap the path in quotes:

```bash
cd "Problem 01"
```
